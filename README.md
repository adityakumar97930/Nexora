# Nexora – Smart Internship Recommendation Portal

## 📌 Project Overview
Nexora is a web-based internship recommendation portal that helps students find internship opportunities quickly and easily. The platform allows users to search internships by company, role, and location through a simple and responsive interface.

---

## 🚀 Features

- User Registration and Login
- Search Internships
- View Internship Details
- Responsive User Interface
- SQLite Database Integration
- Dockerized Deployment

## ▶️ How to Run the Project

### Clone the Repository

```bash
git clone https://github.com/adit4525/Nexora.git
```

### Go to the Project Folder

```bash
cd Nexora
```

### Build Docker Image

```bash
docker build -t nexora .
```

### Run Docker Container

```bash
docker run -p 5000:5000 nexora
```

Open your browser and visit:

```
http://localhost:5000
```
